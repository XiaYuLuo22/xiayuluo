YOUR DEVICES

共享工作区

在手机「任务」页核对同一编号。手机指令按电脑当前执行方式运行；结果保存回原会话。完整项目目录仅在电脑显示。

手机配对

仅通过你配置的 HTTPS 服务连接，电脑需要保持在线。模型密钥和屏幕截图不向手机同步；执行方式、目录及权限只能在电脑配置。自动模式下已配对手机可直接提交编程执行。

在手机「设备」页输入你的 HTTPS 同步地址，并粘贴以下邀请。5 分钟有效，只能使用一次；请勿分享给他人。

CLIENT EVENT TRACE

请求与事件日志

记录当前窗口观测到的请求、SSE 和工具操作，最多保留 300 条。

日志只保存在当前窗口内存，刷新后清空。密钥与截图始终过滤；关闭文本记录会移除已有日志中的文本。日志不包含 Codex 内部推理。

Codex 自动接入

启动后自动检测官方 CLI 的 ChatGPT 登录…

ChatGPT / Codex 桌面窗口是否打开不作为连接依据。首次需安装官方 Codex CLI 并通过 codex login 选择 ChatGPT 登录；以后复用其官方登录，无需每次配置。检测不发送聊天、不消耗模型 API、不读取 Cookie 或复制令牌。登录已识别不等于服务网络及额度已验证，实际回复时仍重新校验。保留你显式选择的 API 来源，不会偷偷切换或失败回退付费 API。

执行方式

自动模式会直接发送聊天上下文、执行指定项目的 Codex 任务、有效截图点击及用户要求的记忆保存。可能修改文件或发生不可撤回的点击。此授权仅针对本机已配置权限，不关闭沙箱或设备校验；操作仍可停止，已发生的变更不会撤回。麦克风按已授权的原生启动设置尝试开启，仍需系统权限，可随时停止。系统授权、账号登录和安装器提示仍由系统控制。

语音唤醒 · 夏鱼洛

正在读取语音状态…

原生 Windows App 打开后自动尝试一次待命，不用先进入设置。缺少语音依赖、离线模型、系统中文声音或麦克风/聊天权限时不会假装已开启。系统麦克风授权仍需本人允许。停止后本次不自动重启，可手动开启，下次打开再尝试；.env 的 VOICE_AUTOSTART=false 可关闭自动待命。顶栏运行中的麦克风指示器可直接停止。浏览器、云端和 --serve 不自动监听。

本地识别不保存/上传环境录音，唤醒后文字、上下文和相关记忆发给 Codex；持续待命会增加耗电。语音通道仅只读问答，停止即撤销，不使用付费 API。最小化可继续，退出、睡眠或麦克风被占用可能中断，不保证始终可用。唤醒后 30 秒可连续说话；“结束对话”返回待唤醒，“停止监听”关闭麦克风。回答时暂停识别，不支持语音打断。详见 VOICE.md。

日常对话来源

Codex 方式调用电脑上的官方 CLI，不控制 Codex 桌面窗口、不提取登录令牌。默认同意时，发送后直接把近期会话及相关记忆交给 Codex 回复；手机也无需到电脑逐轮确认。可在上方切回逐次确认。仍受会员额度限制，不保证逐字输出，不回退付费 API。

先安装官方 npm install -g @openai/codex，再执行 codex login 并选择 ChatGPT 登录。仅安装桌面 Codex App 不代表已安装 CLI。普通问答不需要 CODEX_WORKSPACE；编程模式仍需指定项目目录。

连接模型与 Codex（首次使用）
Codex 登录问答无需模型 API 密钥；使用 API 时才需在本机 .env 配置连接并重启。桌面原生菜单「夏鱼洛 → 打开配置目录」可找到此文件。模型密钥只写入本机，界面不会读取或展示它。
CHAT_PROVIDER=auto
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4.1-mini
CODEX_WORKSPACE=C:/Users/you/projects/my-project
CODEX_SANDBOX=read-only
DESKTOP_ENABLED=true
Codex 使用本机安装的 CLI：先运行 npm install -g @openai/codex，再运行 codex login。需要它修改项目时，将沙箱改为 workspace-write。

        
记忆与隐私
记忆和对话保存在 .assistant/memory.sqlite3；临时记忆只在运行中的服务内保留，重启后清空。历史对话不等于永久记忆。
发送对话时，近期上下文及最多 6 条相关记忆会发送给配置的模型服务。Codex 任务交给其自身配置的服务；其他时间不会后台发送屏幕或记忆。
